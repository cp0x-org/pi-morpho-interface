Morpho Permissionless Interface by cp0x

cp0x runs this open-source, permissionless interface for the Morpho protocol. Use your own wallet to interact directly with Morpho smart contracts. cp0x never holds user funds and does not block access to the interface by country. The interface loads no analytics or tracking scripts.

  • Deposit into and withdraw from Morpho Vaults V1.
  • Supply assets and collateral, borrow and repay on Morpho Blue variable-rate markets.
  • Lend and borrow at fixed rates on Morpho Midnight.
  • View your positions across networks in the portfolio.

View the source code on GitHub and find more interfaces at Permissionless Interfaces by cp0x.
